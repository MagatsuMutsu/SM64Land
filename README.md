# AP SM64Land
Il s'agît d'un Manual Archipelago combiné avec du Retroachievements d'un fangame de Super Mario 64 créé par Kaze Emanuar.
Prenez de fichier Apworld, mettez le dans Custom World dans votre Dossier Archipelago.
Le Yaml, pensez à mettre votre nom et mettez le dans Player si vous créez le salon, sinon fournissez le à l'hôte.
Où trouver le jeu? Vous avez déjà les outils, je n'en dirais pas plus.
C'est testé et fonctionnel.
